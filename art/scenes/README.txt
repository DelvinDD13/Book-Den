Cut-out shapes for the series scenes (src/l53.js). Each file is only an outline (white with transparency) of the figure, the sky
or the gap behind the figure on one cover painting, traced from the cover as Apple's image server serves it. The paintings
themselves are not stored in this repository: the app loads the cover on the phone and lays these shapes over it, and only
when the cover's address still matches the one the shapes were traced from.
